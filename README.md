## 🚀 التثبيت والبدء السريع

### المتطلبات
- Node.js 14 أو أحدث
- npm أو yarn
- رمز بوت Telegram

### خطوات التثبيت

```bash
# 1. انسخ المشروع
git clone <repo-url>
cd masjid-bot

# 2. ثبّت الحزم
npm install

# 3. أنشئ ملف .env
echo BOT_TOKEN=YOUR_TOKEN_HERE > .env
echo DEVELOPER_IDS=123456789,987654321 >> .env

# 4. شغّل البوت
node index.js
```

### متغيرات البيئة

| المتغير | الوصف | مثال |
|---------|-------|------|
| `BOT_TOKEN` | رمز البوت من @BotFather | `123456789:ABCdefGHIjklmnoPQRstuvWXYZ` |
| `DEVELOPER_IDS` | معرفات مطورين (اختياري) | `123456789,987654321` |

```

       ↓ أدخل الاسم والهاتف والوصف
البوت: يحفظ الطلب
المسؤول: يرى الطلب في لوحة التحكم
```

## 🔒 الأمان والصلاحيات

### التحكم بالوصول

**مستويات الصلاحيات:**
1. **مصلي عادي** (Worshipper) - صلاحيات محدودة
2. **شيخ/إمام** (Sheikh) - صلاحيات متوسطة
3. **مسؤول مسجد** (Admin) - صلاحيات عالية
4. **مطور** (Developer) - صلاحيات كاملة

**التحقق من الصلاحيات:**
```javascript
if (![ROLES.ADMIN, ROLES.DEVELOPER].includes(ctx.user?.role)) {
  return ctx.reply('⛔ ليس لديك صلاحية.');
}
```

### حماية البيانات
- ✅ حفظ محلي آمن في `data/db.json`
- ✅ لا توجد مشاركة بيانات خارجية
- ✅ تحقق من الصلاحيات في كل طلب
- ⚠️ احفظ نسخة احتياطية من البيانات بانتظام
